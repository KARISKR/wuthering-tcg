# 안티그라비티 작업 지시 표준 운영 규칙 (SOP)

본 프로젝트(Wuthering Waves TCG / 명조: 대결 TCG)의 모든 코드 수정, 리팩토링, 버그 수정, 기능 추가 작업 시 아래 규칙을 **최우선 기본 원칙(Default Rules)**으로 항상 준수해야 합니다.
(근거 문서: `_docs/안티그라비티_작업지시_표준문구.md`, `_docs/명조_대결_TCG_작업_계획서.md` 「재발 방지 규칙」)

## 1. 진행 기본 원칙
1. **지시된 한 단계만 수행 (One Step at a Time)**: 한 번에 지시된 단계 하나만 수행하고 완료 시 멈춰서 보고.
2. **코드 수정 전 사전 동작 측정 (Measure Before Modifying)**: 변경 전 동작을 숫자로 먼저 측정하여 보고서에 명시.
3. **옛 방식 vs 새 방식 비교 테스트 선행 (Parity Test First)**: 변경 전 50판 이상 시드에서 차이 0건 확인 및 의도적 버그 주입 시 실패 확인.
4. **원본 함수 직접 열람 (Inspect Implementation Source)**: 값 생성 로직 원본 직접 확인.
5. **저장·전송 데이터 크기 상한 테스트 (Enforce Size Limits)**: 리플레이 v2 30KB 이하, 지문 64자 이하, GameBoard 800줄 이하, any 85건 이하 유지.
6. **추측 금지 및 불일치 시 즉각 중단 (No Guessing, Halt on Ambiguity)**: 코드와 지시서가 다르면 즉시 멈추고 질문.

## 2. 작업 보고서 필수 양식 준수
- 수치는 명령 실행 결과 원문 기재 (요약 금지)
- 제출 전 자가 점검 6대 명령 실행 및 출력 기재
