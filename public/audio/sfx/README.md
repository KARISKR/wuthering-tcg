# 🔊 명조: 대결 TCG - 커스텀 효과음(SFX) 규격 및 가이드

이 폴더(`public/audio/sfx/`)에 각 카테고리별로 원하는 음원 파일(`.mp3`, `.wav`, `.ogg`, `.webm`)을 넣어두면, 게임 플레이 시 Web Audio 합성음 대신 **사용자가 넣은 커스텀 효과음 파일이 최우선으로 자동 재생**됩니다.

파일이 없거나 로드에 실패할 경우, 엔진 내장 고품질 물리 합성음(Heavy Sub Bass & Visceral Impact)으로 자동 폴백(Fallback)되어 끊김 없이 작동합니다.

## ⏱️ 2. 왜 효과음 길이가 중요한가요?

- **카드 게임 특성상 연속 조작 발생**:
  - TCG 대전 중에는 카드 연타, 연격 공격, 페이즈 전환이 1초 안에도 빠르게 연속으로 일어날 수 있습니다.
  - 효과음 길이가 2초 이상으로 너무 길면 소리가 지저분하게 겹치거나(Audio Clutter), 다음 액션의 사운드를 덮어버릴 수 있습니다.
- **초반 어택(Transient / Attack Time)**:
  - 파일 시작 부분에 **무음(Silence) 구간이 없어야** 버튼을 누르거나 카드가 부딪히는 순간 즉각(0ms 딜레이) 소리가 반응합니다.
  - Audacity 등 무료 편집기에서 앞부분 무음을 잘라내고(Trim) 넣어주시면 가장 손맛이 좋습니다.

## 🛠️ 3. 지원 포맷 및 음량 기준

1. **지원 확장자**: `.mp3`, `.wav`, `.ogg`, `.webm`, `.m4a`
2. **권장 샘플레이트**: 44.1kHz 또는 48kHz (16-bit / 24-bit)
3. **권장 음량 (Loudness)**: -12 LUFS ~ -16 LUFS (피크 0dB 넘지 않도록 리미터 권장)
4. **우선순위 순서**:
   - `clash.mp3` -> `clash.wav` -> `clash.ogg` -> `clash.webm` 순으로 자동 탐색하여 발견되는 즉시 로드합니다.
