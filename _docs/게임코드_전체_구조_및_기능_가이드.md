### 핵심 설계 원칙
1. **엔진 순수성**: `src/engine/` 내부는 비결정적 전역 함수(`Math.random`, `Date.now`, `new Date`, `performance.now`)를 호출하지 않고 `rng.ts`의 시드 기반 PRNG(`engineRandom`, `aiRandom`)와 단조 증가 카운터(`engineTick`)만 사용합니다.
2. **단일 상태 전이 (`step`)**: 모든 게임 상태 변경은 `step(state, action)` → `BattleSource` → `BattleStore`를 통해 이루어지며, UI에서 직접 `setGameState`를 임의로 호출하지 않습니다.
3. **데이터 중심 카드/리플레이 저장**: 리플레이 v2는 전체 상태 스냅샷 대신 `{ start, actions, fingerprint }`만 저장하여 개당 30KB 이하(평균 약 5KB)를 유지합니다.
