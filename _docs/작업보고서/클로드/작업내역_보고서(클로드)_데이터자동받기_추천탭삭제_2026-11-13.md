# 작업 내역 보고서 (클로드) — 게임 데이터 자동 받기, 전투 덱 선택의 「추천」 탭 삭제

## 0. 요약

- **「추천」 탭 삭제**: AI 대전·1인 2역 덱 선택은 「보유 덱 · 공식 · 공유 덱 · 전체」, 멀티 대기실은 「마이 덱 · 👑 공식 · 🌐 공유 덱」. 추천 덱 4종(sldark)은 공유 덱 탭에 그대로 있다. 기본 제공 덱은 공식 스타터 SD01·SD02만.
- **게임 데이터 자동 받기**: 로비가 열리고 10초 뒤부터 배경에서 동시 2개씩 받는다(`startAutoOfflinePack`). 로비를 떠나면(전투·덱 빌더) 멈추고(`stopAutoOfflinePack`), 다시 로비에 오면 빠진 것만 이어 받는다. 다 받으면 완료 표시가 남아 더 받지 않는다.
  - 받지 않는 경우: 브라우저가 데이터 절약 모드(`saveData`)이거나 모바일 데이터(`connection.type === 'cellular'`)라고 알려 줄 때. 아이폰처럼 알려 주지 않는 브라우저는 받는다.
  - 자동 받기에서는 저장 공간 유지 요청(`navigator.storage.persist`)을 하지 않는다 (파이어폭스가 확인 창을 띄우므로). 직접 받기 버튼을 누를 때만 요청.
  - 직접 받기 버튼을 누르면 자동 받기를 멈추고 이어서 받는다 (겹치지 않게).
- **안내 문구**: 「데이터 받기」 창 — "로비에 있는 동안 자동으로 조금씩 받아집니다. 전투에서 대사·카드가 늦게 나오는 등 문제가 있을 때만 아래 버튼으로 한 번에 받아 주세요. 이미 받은 파일은 건너뜁니다." + "데이터 절약 모드나 모바일 데이터로 접속하면 자동으로 받지 않습니다."
- 처음 전투 때 "받으시겠습니까?" 창은 만들지 않았다 (자동 받기로 대신, 사용자 결정).
