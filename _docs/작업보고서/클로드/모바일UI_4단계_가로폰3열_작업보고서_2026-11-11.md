### 구현 방식
- 카드 크기: 각 진영 열을 CSS container로 두고 `--phone-card-w = min((열 폭 − 20px)/3.3, (열 높이 − 104px) × 0.6)`. 리더 1.12배. 화면 폭·높이가 달라도 열 안에서 자동으로 맞춰짐.
- 글씨: 전부 고정 px, 최소 10px (숫자 11~13px). zoom 없음.
- 동작: 기존 `OpponentFieldArea` / `PlayerFieldArea` / `CenterClashArena`와 **같은 콜백을 같은 조건식으로** 호출 (조건식은 `PhoneBattleBoard`에 원본에서 그대로 옮김).
- 노치: 좌우·하단 `env(safe-area-inset-*)` 여백.
- 상단 바의 📱/🖥️ 토글로 🖥️를 고르면 기존 전장으로 돌아감.

### 기존 대비 빠진 것 (가로 폰 3열 전장에서만)
- 리더 방치 말풍선(이스터에그) 미표시
- 캐릭터 카드 하위 카드 부채꼴 펼치기 대신 "스택 n" 배지 (탭 → 진화 계보 창, 기존과 같은 창)
