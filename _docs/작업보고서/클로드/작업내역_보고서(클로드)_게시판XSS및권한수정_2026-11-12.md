## 0. 요약

- **1번 XSS**: 로비 공지·게시글 보기·글 편집기 세 곳의 정규식 정리를 DOMPurify로 바꿨다. `<img src=x onerror=…>`, `<svg onload=…>`가 이제 실행되지 않는다(테스트와 브라우저에서 확인).
- **2번 권한**: 서버가 글·댓글을 고치거나 지울 때 비밀번호 또는 관리자 키를 확인한다. 공지는 관리자 키가 있어야만 켤 수 있다. 권한이 없는 요청은 추천·비추천·조회수만 +1까지 반영된다.
- **3번 노출**: 응답에서 글·댓글 비밀번호를 뺐다(`hasPassword`로만 표시). 비밀글 본문은 비밀번호 헤더가 맞을 때만 보낸다.
- **4번 일부**: 번들에 있던 게시판 관리자 비밀번호를 지웠다. 관리자 확인은 서버 환경 변수 `ADMIN_KEY`로 한다.
- **배포 전 필수**: Cloudflare Pages 환경 변수에 `ADMIN_KEY`를 새 값으로 설정해야 한다. 옛 비밀번호는 이미 공개됐으므로 쓰지 않는다. 설정하지 않으면 공지 작성·수정이 모두 막힌다.

## 7. 브라우저 확인

- **환경**:
  - `npx wrangler@4 pages dev dist`로 로컬 함수와 D1을 띄웠다.
  - 상태 파일은 저장소 밖 임시 폴더에 두었고, 테스트용 관리자 키로 실행했다.
  - 이 환경은 점검 모드라 로컬에서만 `sessionStorage` 우회를 켰다.
- **확인한 것** (내장 브라우저, `http://localhost:8788`):
  1. 비밀글을 틀린 비밀번호로 열면 "❌ 비밀번호가 일치하지 않습니다."가 뜨고, 맞는 비밀번호로 열면 "비밀글 (잠금 해제됨)"과 함께 본문이 보인다.
  2. `<img src=x onerror=…>`가 든 글을 열면 렌더 결과가 `<img src="x">`이고 실행 흔적 변수가 `null`이다.
  3. 틀린 비밀번호로 글 수정을 누르면 편집기가 열리지 않는다. 틀린 비밀번호로 댓글을 삭제하면 서버의 댓글 수가 그대로 1이다.
  4. 맞는 비밀번호로 댓글을 삭제하면 서버 댓글 수가 0이 된다. 맞는 비밀번호로 글을 수정해 저장하면 서버 제목이 "수정된 제목"으로 바뀌고 `hasPassword: true`가 유지된다. 응답에 비밀번호는 없다.
  5. 공지 말머리에 틀린 키를 넣으면 말머리가 GENERAL로 돌아간다. 맞는 키를 넣으면 공지가 등록되어 로비 API `latestNotice`로 나온다.
  6. curl로 권한 없이 기존 글을 덮어쓰려 하면 제목이 바뀌지 않는다. 시드 데이터로 우연히 확인했다.
- **콘솔 오류**: 404는 모두 테스트 이미지 `/x` 요청이었다. 그 밖에 "An unknown error occurred when fetching the script" 3건이 있었는데, 이번 변경과 관계있는지는 확인하지 못했다.
- **캡처**: 없음 (확인 값은 위 출력 원문)

## 9. 멈추고 물어볼 것

- **배포 전**: Cloudflare Pages(프로덕션·프리뷰)에 `ADMIN_KEY` 환경 변수를 **새 값**으로 설정해야 한다. 설정 전에 배포하면 공지 작성·수정·삭제가 막힌다. 기존 공지는 그대로 보인다.
- **추천 처리**: 권한 없는 사용자의 추천은 +1만 되고 취소(−1)는 서버에 반영되지 않는다. 코드에 `shortcut:` 주석으로 남겼다. 정확히 하려면 추천/취소 전용 요청이 필요하다(점검 보고서 6번 덱 수정과 같은 방식).
- **DB에 남은 비밀번호**: 기존 글·댓글 비밀번호는 DB에 평문으로 남아 있다. 응답에는 더 이상 나가지 않는다. 해시로 바꾸려면 DB 데이터 이전이 필요하다.
