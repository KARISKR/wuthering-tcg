## 0. 점검 요약

클로드가 추가한 신규 카드 5종(`TP01-001`~`TP01-005`)의 데이터·이미지·엔진·UI 연동을 기존 코드베이스 방식과 대조 점검했습니다.
카드 이미지(`TP01-001`~`TP01-005`) 대비 수치와 효과 원문은 정확했으나, 기존 엔진 상태 머신·덱 코드 직렬화·UI 필터 연동 방식과 어긋나는 4건을 발견해 수정·검증 후 `dev`에 커밋 및 푸시했습니다.

1. **`TP01-002 타오르는 넝쿨의 춤` 인간 선택 후 턴 진행 교착 수정** (`src/engine/gameEngine.ts`)
   - `executeBattlePhaseEndStep`의 `RECOVER_FROM_DROP` 선택지에 `endTurnAfterResolve: true`가 빠져 있어, 인간 플레이어가 회수/건너뛰기를 완료해도 `COMBO_STEP`에 그대로 멈추던 문제 수정.
   - 트래시 내 `BP01-050`이 여러 장일 때 `[vines[0]]`만 노출하던 부분을 `vines` 전체 노출로 보완.
2. **덱 코드 V2 직렬화 `TP01` 프리픽스 누락 수정** (`src/utils/deckCode.ts`)
   - `PREFIX_LIST` 끝에 `'TP01'` 추가 (`['BP01', 'SD01', 'SD02', 'BP02', 'SD03', 'PR', 'OTHER', 'TP01']`) 및 미등록 프리픽스 폴백을 `PREFIX_LIST.indexOf('OTHER')`로 고정해 기존 덱 코드 하위 호환성을 유지하면서 `TP01` 카드가 `BP01-044`로 변질되던 문제 해결.
3. **대결 오버레이 변경 스피드 및 `TP01-004` AI 레벨업 배지 누락 보완** (`src/engine/gameEngine.ts`)
   - `finishClashJudgment`에서 `TP01-001`(14)·`TP01-003`(20) 조건 충족 시 `c0.speed`/`c1.speed`도 갱신해 대결 결과 화면에 변경된 스피드가 표시되도록 보완.
   - `applyTp01JudgmentEffects`의 `TP01-004` AI 자동 레벨업 경로에 `triggeredEffects.push(...)`(`effectType: 'BUFF'`) 추가.
4. **덱 빌더/카드 도감 `'일반'`(공용 아이템) 필터 추가** (`src/components/DeckBuilder.tsx`, `src/components/CardCatalogModal.tsx`)
   - `charOptions` / `characterFilterOptions`에 `'일반'` 항목 추가.
