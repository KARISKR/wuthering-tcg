### 사용자가 느끼는 변화
1. **로딩·끊김**
   - 전투 진입 때 BGM이 끊기던 문제를 줄였다. 오디오를 동시 2개 큐로 받고, 전투 BGM은 로비에서 미리 버퍼링한다.
   - 카드가 검게 나오던 문제를 고쳤다. 실패하면 재시도 → 원본 → 이름 순으로 보여준다.
   - 카드 이미지를 처음부터 맞는 크기로 받는다.
   - 덱을 고르는 순간부터 카드를 미리 받는다.
2. **재방문:** 서비스 워커 캐시를 분리했다. 카드·오디오·이펙트는 업데이트해도 다시 받지 않는다. 배포 직후 옛 화면 오류가 나면 자동으로 새로고침한다.
3. **격돌 연출:** 캐릭터 9종의 공격 스프라이트를 격돌·연격·리플레이에 적용했다. 대미지에 따라 3단계로 나뉜다.
4. **로비·메뉴**
   - 로비를 새로 배치했다. 싱글·멀티 큰 카드가 나란히 있고, 멀티 카드에는 일러스트를 넣었다.
   - 모바일 가로 전용 배치를 만들었다.
   - 메뉴 이름과 색(앰버)을 통일했다.
   - 덱 화면 3개(내 덱/추천 덱/공유 덱)를 탭으로 연결했다.
   - 메뉴 화면 카드 썸네일을 축소본으로 바꿨다. 추천 덱 모바일 기준 6.4MB → 1.05MB.
5. **게시판:** 두 사람이 동시에 글이나 댓글을 써도 사라지지 않는다. 도배를 막는 작성 빈도 제한을 넣었다.
6. **서버 비용:** 방 하트비트 7초→20초, 방 목록 4.5초→12초, 접속자 핑 1분→5분(전투 중 중단). 무료 한도 안에서 처리할 수 있는 판수가 늘었다.
