## 1. 확정된 결정 (사용자 확인)

1. 가로 폰만 지원. 세로는 전투·리플레이·**튜토리얼 전투**까지 차단, "세로로 계속 보기" 없음
2. 세로 차단 중에도 멀티플레이 턴 타이머는 그대로 흐름
3. 화면 전체 축소 대신 **화면 높이·입력 방식으로 레이아웃 모드 선택**, 폭 차이는 배치로 흡수
4. 가로 폰: 상대 | 대결 | 나 **3열**
5. 손패: 기본 **살짝 보임**(띠) → 탭하면 펼침, 손패에서 골라야 하는 단계(대결 세트·연격·패 정리)는 **자동 펼침**
6. **태블릿·작은 PC 창은 PC 레이아웃** (터치 태블릿은 좌우 패널 접힌 채 시작)
7. 펼친 손패 카드는 **효과문을 빼고 일러스트를 크게** (효과는 카드 선택 → 🔍 상세)
8. 측정 스크립트는 저장소에 포함 (`playwright-core` devDependency)

## 4. 동작 설명 (가로 폰)

### 전장
- 상단 바 48px(버튼 44px), 전장 확대/축소 버튼 숨김
- 3열: 상대 진영 | 대결 | 내 진영. 카드 크기는 열 크기(CSS container)에 맞춰 자동
- 캐릭터 카드 탭: 진화 가능하면 진화 창, 아니면 진화 계보 창 (기존과 같은 조건). "진화"·"스택" 표시는 버튼이 아니라 표시(터치는 카드 전체)
- 리더 교대: 서포트 카드 위 44px 버튼
- 덱·협주·트래시 칩 탭 → 기존 목록 창, 내 액션덱 칩 → 드로우(가능할 때 강조)
- 대결 슬롯 카드 탭 → 카드 상세
- 노치: 좌우·하단 `env(safe-area-inset-*)` 여백

### 손패 (하단 56px 띠 + 오른쪽 퀵 액션)
- 띠: 카드별 코스트·이름 + 그림 윗부분. 띠 전체가 버튼 → 펼침
- 펼침: 카드 100×140px(그림 88px + 이름 + 코스트/속도/피해), 뒤 보드 어둡게
- 카드 선택: 패널 맨 위에 행동 줄(대결에 세트 / 연격 시전 / 협주 충전 / 🔍 상세 / ✕), 사용 불가 사유는 한 줄
- 자동 펼침: 대결 세트·연격·패 정리 단계 진입
- 자동 접힘: 카드 사용 후(더 고를 것 없을 때), 상대 턴 시작, 바깥 탭, ▼ 접기, 아래로 쓸기
- 퀵 액션(카드·로그·드로우·배틀 선언·턴 종료·패스·연격 종료·버리기)은 손패 띠 오른쪽, 손패 패널이 열려도 위에 보임

### 창(모달)
- 확인·카드 상세·로그·진화·협주 선택·결과·목록·HP 기록·진화 계보: 축소하지 않고 실제 크기, 길면 창 안 스크롤
- 리더 선택·멀리건: 글씨 최소 10px
- 대결 연출·결과: 가로 2열(왼쪽 두 카드 + VS, 오른쪽 결과·피해·효과 목록(설명 2줄)·진행 버튼 하단 고정), 상성 순환 도표는 가로 폰에서 숨김

### 세로
- 터치 기기 세로 → 전투·리플레이·튜토리얼 위에 "가로 모드 전용" 안내(닫기 없음). Android류는 "가로 모드로 전환" 버튼, iPhone류는 회전 잠금 해제 안내
