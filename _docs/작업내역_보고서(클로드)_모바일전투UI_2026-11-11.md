## 1. 확정된 결정 (사용자 확인)

1. 가로 폰만 지원. 세로는 전투·리플레이·**튜토리얼 전투**까지 차단, "세로로 계속 보기" 없음
2. 세로 차단 중에도 멀티플레이 턴 타이머는 그대로 흐름
3. 화면 전체 축소 대신 **화면 높이·입력 방식으로 레이아웃 모드 선택**, 폭 차이는 배치로 흡수
4. 가로 폰: 상대 | 대결 | 나 **3열**
5. 손패: 기본 **살짝 보임**(띠) → 탭하면 펼침, 손패에서 골라야 하는 단계(대결 세트·연격·패 정리)는 **자동 펼침**
6. **태블릿·작은 PC 창은 PC 레이아웃** (터치 태블릿은 좌우 패널 접힌 채 시작)
7. 펼친 손패 카드는 **효과문을 빼고 일러스트를 크게** (효과는 카드 선택 → 🔍 상세)
8. 측정 스크립트는 저장소에 포함 (`playwright-core` devDependency)

## 4. 동작 설명 (가로 폰)

### 전장
- 상단 바 48px(버튼 44px), 전장 확대/축소 버튼 숨김
- 3열: 상대 진영 | 대결 | 내 진영. 카드 크기는 열 크기(CSS container)에 맞춰 자동
- 캐릭터 카드 탭: 진화 가능하면 진화 창, 아니면 진화 계보 창 (기존과 같은 조건). "진화"·"스택" 표시는 버튼이 아니라 표시(터치는 카드 전체)
- 리더 교대: 서포트 카드 위 44px 버튼
- 덱·협주·트래시 칩 탭 → 기존 목록 창, 내 액션덱 칩 → 드로우(가능할 때 강조)
- 대결 슬롯 카드 탭 → 카드 상세
- 노치: 좌우·하단 `env(safe-area-inset-*)` 여백

### 손패 (하단 56px 띠 + 오른쪽 퀵 액션)
- 띠: 카드별 코스트·이름 + 그림 윗부분. 띠 전체가 버튼 → 펼침
- 펼침: 카드 100×140px(그림 88px + 이름 + 코스트/속도/피해), 뒤 보드 어둡게
- 카드 선택: 패널 맨 위에 행동 줄(대결에 세트 / 연격 시전 / 협주 충전 / 🔍 상세 / ✕), 사용 불가 사유는 한 줄
- 자동 펼침: 대결 세트·연격·패 정리 단계 진입
- 자동 접힘: 카드 사용 후(더 고를 것 없을 때), 상대 턴 시작, 바깥 탭, ▼ 접기, 아래로 쓸기
- 퀵 액션(카드·로그·드로우·배틀 선언·턴 종료·패스·연격 종료·버리기)은 손패 띠 오른쪽, 손패 패널이 열려도 위에 보임

### 창(모달)
- 확인·카드 상세·로그·진화·협주 선택·결과·목록·HP 기록·진화 계보: 축소하지 않고 실제 크기, 길면 창 안 스크롤
- 리더 선택·멀리건: 글씨 최소 10px
- 대결 연출·결과: 가로 2열(왼쪽 두 카드 + VS, 오른쪽 결과·피해·효과 목록(설명 2줄)·진행 버튼 하단 고정), 상성 순환 도표는 가로 폰에서 숨김

### 세로
- 터치 기기 세로 → 전투·리플레이·튜토리얼 위에 "가로 모드 전용" 안내(닫기 없음). Android류는 "가로 모드로 전환" 버튼, iPhone류는 회전 잠금 해제 안내

6) oxlint 경고 수: 바뀐 파일 18개 모두 HEAD와 같음 (예: HandView 4→4, GameBoard 6→6, GameOverModal 9→9), 새 파일 0건. `GameBoard.tsx` 663줄 (상한 800)

## 8. 확인하지 못한 것 / 알려진 한계

- **실기기 미확인**: 모든 확인은 PC Chrome(헤드리스)의 휴대폰 흉내. 실제 iPhone Safari / Android Chrome에서 한 번 확인 필요
  - Android에서 "가로 모드로 전환" 버튼(전체화면 + 방향 고정)이 실제로 도는지
  - iPhone 노치·홈 인디케이터 여백
- **연격 단계·패 정리 단계 자동 펼침**: 해당 단계가 나온 판이 없어 실측 못 함 (대결 세트와 같은 조건 방식)
- **아래로 쓸어 손패 접기**: 헤드리스에서 터치 제스처 미확인
- **멀티플레이 화면**: 상대가 사람인 경우(시계·관전자) 실측 없음. 같은 컴포넌트·조건을 쓰므로 표시만 다를 수 있음
- **리플레이 화면**: 데이터가 없어 실측 못 함. 전장 3열은 같은 `BattleLayout`이라 적용되지만, 대결 결과 2열·모달 규칙은 `GameBoard` 아래에서만 걸리므로 리플레이에서는 기존(축소) 방식
- **튜토리얼 전투 가로 화면**: 별도 화면(`ScriptedTutorialBattle.tsx`, 2485줄)이라 3열·글씨 규칙 미적용 (844x390에서 10px 미만 29.7%). 세로 차단만 적용
- **태블릿·PC**: 이번 범위 밖. PC 레이아웃 글씨는 여전히 작음 (예: iPad 1180x820 최소 5.46px)
- 가로 폰 전장에서 빠진 것: 하위 카드 부채꼴 펼치기(→ 스택 표시 + 카드 탭 시 진화 계보), 상대 손패 뒷면 미니 카드(→ "손패 n" 배지, 공개 카드는 "👁 이름" 칩), 리더 방치 말풍선(이스터에그)
- 펼친 손패 카드의 효과문은 표시하지 않음 (요청에 따른 변경, 🔍 상세로 확인)
- `/api/stats`가 `today/total/online` 필드 없이 응답하면 방문자 위젯이 앱 전체를 멈출 수 있음 (`src/utils/visitorStats.ts` 응답 사용부) — 범위 밖이라 미수정

## 9. 재현 방법

```bash
npm run dev
npm run measure:mobile -- --url http://localhost:5173                       # 가로 폰 5종
npm run measure:mobile -- --url http://localhost:5173 --sizes 390x844       # 세로 차단
npm run measure:mobile -- --url http://localhost:5173 --desktop --sizes 1280x720,1920x1080   # PC 회귀
npm run measure:mobile -- --url "http://localhost:5173/?layout=phone" --desktop --sizes 1280x720  # PC에서 가로 폰 배치 강제
npm run measure:mobile -- --url http://localhost:5173 --flow tutorial --sizes 390x844
```
- 결과: `.measure/mobile-battle/<시각>/` (스크린샷, JSON, `summary.json`), git 제외
- 판마다 선후공·손패가 달라 넘침·버튼 수는 상태에 따라 조금씩 다름 → 여러 번 돌려 확인
- 모달·대결 결과·손패 흐름·노치 확인용 스크립트는 작업 폴더(저장소 밖)에서 사용. 필요하면 `scripts/`로 옮길 수 있음
