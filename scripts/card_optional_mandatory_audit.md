## 2. 기존 게임 엔진의 문제점 및 개선 조치 내역

### 🚨 [치명적 문제 지점과 개선 내용]
1. **양양 Lv.0 (BP01-024) & 산화 Lv.0 (BP01-033)**:
   - **공식 원문**: `【리더】【배틀】자신이 청색 카드로 배틀 시, 자신의 덱 위의 카드 1장을 협주 에리어에 배치 가능.`
   - **기존 문제**: 유저의 동의나 선택 없이 청색 카드로 배틀만 돌입하면 무조건 덱 맨 위의 카드를 빼앗아 협주 존으로 강제 투입 (덱 소모/키 카드 유실 초래).
   - **개선 조치**: **`선택 발동 모달(PendingChoice)` 연동 완료!** 청색 카드로 배틀 시 덱 맨 위의 카드를 먼저 확인하고, "협주 에리어에 배치"할지 "배치하지 않고 덱 맨 위에 유지(패스)"할지 유저가 직접 선택할 수 있도록 개편. AI는 최적 선택 자동 처리.

2. **파수인 Lv.0 (BP01-010)**:
   - **공식 원문**: `【리더】【배틀】자신이 녹색 카드로 배틀 시, 자신의 덱 위의 카드 1장을 공개하고 패에 추가 가능.`
   - **기존 문제**: 녹색 카드로 배틀 시 유저 선택권 없이 무조건 자동 드로우.
   - **개선 조치**: 덱 맨 위 카드를 확인 후 "패에 추가"할지 "추가하지 않고 덱 맨 위에 둘지" 선택창 제공.

3. **카멜리아 Lv.0 (BP01-005)**:
   - **공식 원문**: `【리더】【판정】자신이 승리했을 경우, 트래시 에리어에서 <일반 공격> 카드 1장을 패에 추가 가능.`
   - **기존 문제**: 판정 승리 시 트래시 맨 앞의 일반 공격을 유저 의사와 무관하게 자동 회수.
   - **개선 조치**: 트래시 에리어의 일반 공격 후보들을 모달로 띄워 원하는 카드를 골라 회수하거나, 원치 않을 경우 건너뛸 수 있도록 개선.

4. **소리의 변화·강공격 (BP01-065 / BP01-067)**:
   - **공식 원문**: `【콤보】자신의 패 1장을 버릴 수 있다. 패를 버렸을 경우, 이 카드의 데미지 +1.`
   - **기존 문제**: 연격 실행 시 유저가 아끼는 손패 맨 뒤의 카드를 멋대로 버리고 데미지 +1을 시켰음.
   - **개선 조치**: 손패를 버리지 않고 기본 피해로 칠 수 있으며, 유저가 버리기를 지정했을 때만 패를 버리고 +1 데미지 적용.

5. **캐릭터 등장 및 레벨업 시 트래시 회수 / 협주 배치 효과 신규 구현**:
   - `BP01-003 카멜리아 Lv.1`: 레벨업 시 트래시에서 <일반 공격> 1장 패에 추가 **가능**.
   - `BP01-009 파수인 Lv.1`: 레벨업 시 트래시에서 <변주 스킬> 1장 패에 추가 **가능**.
   - `BP01-013 앙코 Lv.1`: 레벨업 시 트래시에서 <앙코 적색 카드> 1장 패에 추가 **가능**.
   - `BP01-026 치샤 Lv.1`: 레벨업 시 트래시에서 <기본 공격> 1장 패에 추가 **가능**.
   - `BP01-032 산화 Lv.1`: 레벨업 시 트래시에서 카드 1장을 협주 에리어에 배치 **가능**.
   - `BP01-017 / BP01-020 방랑자 Lv.1`: 레벨업 시 덱 위 1장을 공개하고 패에 추가 **가능**.
