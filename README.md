# 鳴潮: 対決 (Wuthering Waves: Battle TCG) - 웹 TCG 시뮬레이터

2026년 공식 출시된 실물 트레이딩 카드 게임 **『명조: 대결 (Wuthering Waves: Battle TCG)』**의 룰을 브라우저에서 100% 완전 자동화로 플레이할 수 있도록 개발된 웹 카드 게임 애플리케이션입니다.

---

## 🌟 주요 특징

1. **완전 자동화 룰 엔진 (Pure TypeScript State Machine)**
   - **체력 및 승리 조건**: 20 HP, 상대 체력 0 도달 시 승리
   - **엄격한 페이즈 제어**: 멀리건 -> 시작 단계 -> 드로우 -> 액션 단계 -> 대결 단계 -> 연격 단계 -> 턴 종료
   - **삼각 상성 판정**: `RED (공격/연격) > GREEN (기동/견제) > BLUE (방어/반격) > RED`
   - **속도(Speed) 및 우선권 판정**: 동색 대결 시 속도 비교, 동률 시 턴 플레이어 승리 (BLUE vs BLUE는 무승부)
   - **연격(Combo) 추가타**: RED 승리 또는 카드 [추격 X] 발동 시 연격 단계에서 빨간 카드를 연속 시전
   - **캐릭터 진화 (Lv.0 -> Lv.1 -> Lv.2)**: 목표 레벨 수만큼 패를 소비하여 리더 및 서포터 강화
   - **협주(Concerto) 자원 시스템**: 패를 자원 존에 충전하여 카드 코스트 지불

2. **게임 모드**
   - 🤖 **스마트 AI 봇 대전**: 상성과 패를 계산하여 레벨업, 협주 충전, 대결 심리전을 구사하는 AI 대전
   - 👥 **1인 2역 연습 듀얼**: 양측의 패와 전술을 직접 테스트할 수 있는 솔로 시뮬레이션 모드
   - 🌐 **온라인 웹 대전 확장 준비 완료**: 순수 상태 머신 기반이므로 `server/socketServer.js`를 통해 즉시 웹소켓 멀티 연동 가능

3. **부가 기능**
   - 📖 **인게임 공식 룰북 모달**: 언제든지 전체 규칙과 상성 확인 가능
   - 🗂️ **전체 카드 도감 모달**: 구현된 모든 캐릭터 및 액션 카드(RED, GREEN, BLUE) 스펙 열람
   - 📜 **실시간 전투 기록 로그**: 모든 대결 판정, 속도 비교, 대미지 내역 기록
   - 💥 **박진감 넘치는 대결 컷신 오버레이**: 카드 동시 공개 및 상성 판정 애니메이션

---

## 🚀 로컬 실행 방법

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 시작
npm run dev

# 브라우저에서 http://127.0.0.1:5173/ 접속
```

---

## 🌐 2단계: 다른 사람과의 온라인 웹 대전 확장 방법

프로젝트의 `server/socketServer.js`에 실시간 멀티플레이 방 생성 및 동기화 서버 코드가 마련되어 있습니다.

```bash
# 서버 의존성 설치
npm install express socket.io cors

# 멀티플레이 서버 실행
node server/socketServer.js
```
클라이언트에서는 `socket.io-client`를 통해 `roomId`로 접속하면 1:1 대전이 실시간으로 동기화됩니다.
